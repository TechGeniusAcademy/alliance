# Настройка Stability AI для AI Designer

## Получение API ключа

1. Зарегистрируйтесь на https://platform.stability.ai/
2. Перейдите в раздел API Keys
3. Создайте новый API ключ
4. Пополните баланс (минимум $10 для тестирования)

## Настройка сервера

Добавьте API ключ в файл `.env` в папке `server`:

```env
STABILITY_API_KEY=your_api_key_here
```

## Стоимость генерации

- SDXL 1.0 (1024x1024): ~$0.04 за изображение
- Рекомендуется начать с $10-20 кредитов для тестирования

## Использование

1. Перезапустите сервер после добавления API ключа
2. Перейдите в раздел "AI Дизайнер" в личном кабинете
3. Опишите мебель, которую хотите сгенерировать
4. Дождитесь генерации (обычно 10-30 секунд)

## Примеры запросов

- "Современный диван в скандинавском стиле"
- "Деревянный обеденный стол из дуба"
- "Минималистичная кровать с мягким изголовьем"
- "Роскошное велюровое кресло в ар-деко стиле"

## Технические детали

- API endpoint: `/api/ai/generate-image`
- Требуется авторизация (Bearer token)
- Модель: stable-diffusion-xl-1024-v1-0
- Разрешение: 1024x1024 пикселей
- Формат ответа: base64 изображение

## Обработка ошибок

Система автоматически обрабатывает следующие ошибки:
- 401: Неверный API ключ
- 402: Недостаточно кредитов
- 400: Некорректный запрос
- 500: Внутренняя ошибка сервера

## Ограничения

- Максимальная длина промпта: 2000 символов
- Рекомендуемое время ожидания: 60 секунд
- Rate limit: зависит от вашего тарифного плана

## Оптимизация запросов

Система автоматически улучшает запросы, добавляя:
- "High-quality professional photograph"
- "furniture design, interior design"
- "modern, elegant, studio lighting"
- "4k resolution, detailed textures"

И исключает:
- "blurry, low quality, distorted"
- "ugly, bad anatomy"
- "watermark, text"
