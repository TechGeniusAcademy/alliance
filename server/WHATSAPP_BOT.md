# WhatsApp Бот для уведомлений мастеров

## Описание
WhatsApp бот автоматически отправляет уведомления мебельщикам о новых заказах на аукционе.

## Возможности
- ✅ Автоматическая отправка уведомлений о новых заказах всем активным мастерам
- ✅ Подробная информация о заказе (название, категория, описание, бюджет, срок, адрес)
- ✅ Уведомления о принятых ставках
- ✅ Массовая рассылка с задержкой между сообщениями
- ✅ Проверка существования номера в WhatsApp
- ✅ Форматирование номеров (автоматическое добавление кода страны)

## Настройка

### 1. Установка зависимостей
Уже установлены:
```bash
npm install whatsapp-web.js qrcode-terminal
```

### 2. Первый запуск
При первом запуске сервера WhatsApp потребует аутентификации:

1. Запустите сервер:
```bash
cd server
npm run dev
```

2. В консоли появится QR код:
```
📱 Отсканируйте QR код в WhatsApp:
[QR CODE]
```

3. Откройте WhatsApp на телефоне:
   - Перейдите в **Настройки** > **Связанные устройства**
   - Нажмите **Связать устройство**
   - Отсканируйте QR код из консоли

4. После сканирования появится сообщение:
```
✅ WhatsApp клиент готов к работе!
```

### 3. Сессия сохраняется
После первой аутентификации сессия сохраняется в папке `whatsapp-session/`.
При следующих запусках сервера QR код не понадобится.

## Как работает

### Автоматическая отправка при создании заказа
Когда клиент создает новый заказ:
1. Заказ сохраняется в базе данных
2. Система находит всех активных мастеров с номерами телефонов
3. Формируется сообщение с деталями заказа
4. Отправляются WhatsApp уведомления всем мастерам (с задержкой 2 сек между сообщениями)

### Формат сообщения
```
🔔 Новый заказ на аукционе!

 Заказ #123
Кухонный гарнитур на заказ

📂 Категория: Кухня

📝 Описание:
Требуется изготовить кухонный гарнитур...

💰 Бюджет: 150,000 - 200,000 ₸

📅 Срок выполнения: 15.12.2025

📍 Адрес доставки: г. Алматы, ул. Абая 123

🔗 Сделайте ставку: http://localhost:5173/master/commissions

Не упустите возможность получить новый заказ! ⚡
```

## Требования к номерам телефонов

### Формат в базе данных
Номера должны быть в таблице `users` в поле `phone` для пользователей с `role = 'master'`.

Поддерживаемые форматы:
- `+77001234567` (с кодом страны)
- `77001234567` (без +)
- `87001234567` (автоматически конвертируется в 77001234567)
- `7001234567` (автоматически добавляется 7 в начало)

### Важно
- Номер должен быть зарегистрирован в WhatsApp
- Система автоматически проверяет существование номера перед отправкой
- Если номер не найден, отправка пропускается с предупреждением в логах

## Дополнительные функции

### Уведомление о принятой ставке
Автоматически отправляется мастеру, когда клиент принимает его ставку:
```typescript
await whatsappService.sendBidAcceptedNotification(masterPhone, {
  id: orderId,
  title: orderTitle,
  acceptedPrice: bidPrice,
  customerName: customerName
});
```

### Массовая рассылка
Для отправки уведомлений нескольким мастерам:
```typescript
const notifications = masters.map(master => ({
  phone: master.phone,
  orderData: {
    id: order.id,
    title: order.title,
    // ... остальные данные
  }
}));

await whatsappService.sendBulkNotifications(notifications, 2000);
```

## Безопасность

1. **Сессия WhatsApp** хранится локально в `whatsapp-session/`
2. Добавьте папку в `.gitignore`:
```
whatsapp-session/
.wwebjs_auth/
.wwebjs_cache/
```

3. Не передавайте сессию другим пользователям

## Ограничения WhatsApp

- **Задержка между сообщениями**: рекомендуется минимум 2 секунды
- **Лимит сообщений**: ~256 сообщений в день (неофициально)
- **Блокировка**: При массовой рассылке WhatsApp может временно заблокировать аккаунт
- **Бизнес аккаунт**: Для большего лимита используйте WhatsApp Business API

## Устранение проблем

### QR код не появляется
1. Убедитесь, что установлены все зависимости
2. Проверьте, что порты не заблокированы
3. Удалите папку `whatsapp-session/` и перезапустите сервер

### Сообщения не отправляются
1. Проверьте статус клиента: `whatsappService.isClientReady()`
2. Убедитесь, что номера в правильном формате
3. Проверьте логи на наличие ошибок

### "WhatsApp клиент не готов"
Подождите несколько секунд после запуска сервера, пока клиент инициализируется.

## Тестирование

Для тестирования создайте заказ через интерфейс клиента:
1. Убедитесь, что у мастеров заполнены номера телефонов
2. Создайте новый заказ
3. Проверьте консоль сервера на наличие логов отправки
4. Проверьте WhatsApp мастеров на наличие уведомления
